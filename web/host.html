Input settings

For browser games choose Keyboard. Save, then click inside the game on the PC so it has keyboard focus. Phone presses type into the focused PC app, not just the game. Keep the game focused while playing.

Each button can hold one key. Choose Unassigned to disable it. Stick directions are digital in keyboard mode.

Safety: inputs release on disconnect or after a short input timeout. Do not use this to type passwords. Windows may block input into elevated apps or games that reject simulated keys.
